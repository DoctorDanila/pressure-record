# Pressure Record

Сервис самоконтроля артериального давления (СКАД): дневник серий измерений, аналитика динамики и экспорт исходных данных для обсуждения с лечащим врачом.

> Сервис не ставит диагнозов, не назначает лечение и не заменяет консультацию врача. Самостоятельная коррекция терапии по данным дневника недопустима.

## Структура

- `core/user` — регистрация, авторизация и подтверждение email.
- `core/setting` — индивидуальные пороги, настройка исключения первого дня и справочник тонометров.
- `core/record` — серии измерений, исходные показания и аналитика.
- `frontend` — React + TypeScript + Vite, Gravity UI, Tailwind CSS и Recharts.
- `web` — публичный каталог: Yii2 API entrypoint и собранное SPA-приложение в `web/dist`.
- `Методика_дашборда_давления.md` — методика расчёта и визуализаций.

## Backend

Требования: PHP 8.1+, Composer и база данных, совместимая с конфигурацией `config/db.php`. Пример окружения находится в `.env.example`.

```bash
composer install
cp .env.example .env
# Заполнить DB_DSN, учётные данные БД, APP_SECRET и параметры почты.
php yii migrate
```

Миграции регистрируются через `config/console.php`:

1. `m261122_000001_create_user_tables` — `user`, `user_setting`, `device`.
2. `m261122_000002_create_record_tables` — `record_series`, `record_measurement`.

`settings` использует `user_setting` и `device`, созданные первой миграцией. Отдельная дублирующая миграция для этих таблиц не требуется.

### API

Все новые API-маршруты работают в том же домене и используют `auth_token` HttpOnly cookie.

| Метод  | URL                                   | Назначение                                                        |
|--------|---------------------------------------|-------------------------------------------------------------------|
| POST   | `/api/auth/register`                  | Регистрация                                                       |
| POST   | `/api/auth/login`                     | Вход                                                              |
| POST   | `/api/auth/logout`                    | Выход                                                             |
| GET    | `/api/auth/me`                        | Текущий пользователь                                              |
| GET    | `/api/auth/verify-email?id=…&token=…` | Подтверждение email                                               |
| GET    | `/api/settings`                       | Конфигурация и список тонометров                                  |
| PUT    | `/api/settings/update`                | Обновить конфигурацию порогов                                     |
| POST   | `/api/devices/create`                 | Добавить тонометр                                                 |
| DELETE | `/api/devices/{id}/delete`            | Удалить тонометр                                                  |
| GET    | `/api/records`                        | Список серий (`from`, `to`, `slot`, `planned`, `limit`, `offset`) |
| POST   | `/api/records/create`                 | Создать серию из 2–3 показаний                                    |
| GET    | `/api/records/{id}`                   | Получить серию                                                    |
| DELETE | `/api/records/{id}/delete`            | Удалить серию                                                     |
| GET    | `/api/records/dashboard`              | Сводные показатели и данные графиков                              |
| GET    | `/api/records/export.csv`             | Экспорт исходных показаний и снимка порогов                       |
| GET    | `/api/records/export.pdf`             | Экспорт исходных показаний и снимка порогов                       |

Пример создания серии:

```json
{
  "slot": "morning",
  "is_planned": true,
  "device_id": 1,
  "measurements": [
    { "systolic": 128, "diastolic": 82, "pulse": 71 },
    { "systolic": 126, "diastolic": 80, "pulse": 70 }
  ],
  "notes": "Самочувствие обычное",
  "symptoms": []
}
```

Коды слотов: `morning`, `day`, `evening`, `unscheduled`. Поддерживаемые коды симптомов: `headache`, `weakness`, `drowsiness`, `dizziness`, `nausea`, `palpitations`, `chest_discomfort`, `shortness_of_breath`, `other`. Список можно расширять на уровне `RecordService` и интерфейса.

## Frontend

Node.js 20+ и npm:

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Vite складывает сборку в `web/dist`. Apache-конфигурация в `web/.htaccess` передаёт `/api/*` в Yii2, существующие файлы отдаёт напрямую, остальные URL направляет на SPA entrypoint. Поэтому корневой каталог сайта должен быть `web/`.

Для локальной разработки API проксируется на `VITE_API_PROXY` (по умолчанию `http://localhost:8080`). Например, из корня проекта можно запустить Yii2 через `php -S localhost:8080 -t web`.

## Правила серий и аналитики

- Серия содержит два или три показания. Если хотя бы по САД или ДАД первые два отличаются более чем на 10 мм рт. ст., сервер требует третье.
- Для трёх показаний размах САД или ДАД более 10 мм рт. ст. отмечает серию как низкодостоверную; исходные показания не удаляются, аналитическая точка берётся по медиане.
- Для обычной серии аналитическая точка рассчитывается по среднему арифметическому. Сохраняются и среднее, и медиана в вычисляемом представлении.
- Внеплановые серии остаются в исходных данных и на графике, но не включаются в плановые средние, недельные категории и тренд.
- Скользящее среднее использует серии за последние семь календарных дней.
- Тренд рассчитывается только при наличии не менее 10 учитываемых плановых серий.
- Пороговые настройки копируются в каждую серию. Изменение конфига не переписывает историю.
- Первый день не удаляется. Опция профиля исключает его только из аналитических расчётов.

Время серии сохраняется в локальной временной зоне `Europe/Moscow`.
